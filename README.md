# Mock E-Com Cart — V3 (Vibe Commerce) - Final

This final version includes:
- 10 product images (stable URLs)
- Professional Light Theme receipt with PDF download
- React frontend and Express+SQLite backend

## Run
1. Backend
```
cd backend
npm install
npm start
```
2. Frontend
```
cd frontend
npm install
npm start
```
Open http://localhost:3000
